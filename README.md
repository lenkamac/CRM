My CRM system project, which is custom-built for a sales manager based on their requirements. It is currently in its initial phase and will be expanded gradually. 
The project is built using Python and Django on the backend, and HTML, CSS, JavaScript, and Bootstrap 5 on the frontend. The database is PostgreSQL.
